# SBOannotator GUI Components

This project is the graphical user interface version of SBOannotator, providing a user-friendly interface for SBO (Systems Biology Ontology) annotation. Below are the functional descriptions of each component:

## Main Components

### 1. `main.py`
**Main Application Entry Point**
- Contains complete PyQt5 GUI application logic
- Handles all user interface interactions and events
- Manages multi-threaded operations, including:
  - SBO file update checking
  - SBOannotator execution
  - LLM recommendation processing
- Coordinates data flow and workflow between components
- Provides file upload, download, and database configuration functionality

### 2. `winUI.py` and `winUI.ui`
**User Interface Definition**
- `winUI.ui`: UI file generated by Qt Designer, defining interface layout and components
- `winUI.py`: Python code automatically generated from UI file, containing the interface class `Ui_MainWindow`
- Provides two main tabs:
  - **Fetch SBO files**: SBO file retrieval and updates
  - **Running SBOannotator**: SBO annotation tool execution interface
- Contains GUI components like tables, buttons, and text boxes for result display and user interaction

### 3. `sboannotator/`
**SBO Annotation Core Module**
- Automatically assigns Systems Biology Ontology terms to SBML models
- Main functions:
  - Parse SBML model files
  - Automatically infer SBO terms based on reaction types, metabolite characteristics, etc.
  - Support database configuration and custom annotation rules
  - Provide enhanced annotation functionality to improve annotation accuracy
- Contains multiple submodules for different annotation strategies and data processing

### 4. `ols_fetch_from_github/`
**SBO File Management Module**
- Retrieves and updates SBO-related files from GitHub repository
- Main functions:
  - Check for SBO file updates on GitHub
  - Download latest versions of SBO files
  - Compare differences between local and remote files
  - Handle user-uploaded files
  - File format conversion and validation
- Ensures use of the latest SBO term definitions

### 5. `ml_sbo/`
**Machine Learning SBO Prediction Module**
- Uses deep learning models for SBO term prediction
- Main functions:
  - Predict appropriate SBO terms based on EC numbers and reaction descriptions
  - Provide confidence scores and prediction explanations
  - Support model training, data preparation, and inference
- Contains submodules:
  - `src/train.py`: Model training logic
  - `src/prepare.py`: Data preparation and preprocessing
  - `src/infer.py`: Model inference and prediction

## Workflow

1. **Launch Application**: Run `main.py` to start the GUI application
2. **Fetch SBO Files**: Application automatically checks and updates SBO files
3. **Upload Model**: User selects SBML model files for annotation
4. **Configure Database**: Optional database configuration modifications
5. **Run Enhanced Annotation**: Use traditional methods for SBO annotation
6. **LLM Recommendations**: Optional use of machine learning models for more precise annotation suggestions
7. **Review and Apply**: Users can review recommendation results and choose to accept or reject them
8. **Download Results**: Save the annotated SBML model files

## Technical Features

- **Multi-threaded Processing**: Prevents GUI freezing, providing smooth user experience
- **Modular Design**: Clear component responsibilities, easy to maintain and extend
- **User-friendly**: Provides intuitive graphical interface and detailed progress feedback
- **Flexible Configuration**: Supports database configuration and annotation parameter adjustment
- **AI Enhancement**: Combines traditional rules and machine learning methods to improve annotation quality
